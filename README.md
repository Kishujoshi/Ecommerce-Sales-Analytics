# 📊 E-Commerce Sales Analytics Dashboard

## 📌 Project Overview
This project focuses on analyzing e-commerce sales data using SQL, Python, and Power BI to generate business insights and interactive dashboards.

The analysis includes:
- Sales trends
- Profitability analysis
- Customer insights
- Regional performance
- Product analysis
- Discount impact analysis

---

## 🛠 Tools & Technologies
- PostgreSQL
- DBeaver
- SQL
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI

---

## 📂 Project Workflow

### 1️⃣ Data Collection
Imported Superstore sales dataset into PostgreSQL database.

### 2️⃣ SQL Analysis
Performed business analysis using SQL queries:
- Total sales & profit
- Top customers
- Region-wise analysis
- Product profitability
- Discount impact

### 3️⃣ Python EDA
Conducted exploratory data analysis using Python:
- Data cleaning
- Trend analysis
- Correlation analysis
- Visualizations

### 4️⃣ Power BI Dashboard
Built interactive dashboards to visualize:
- KPIs
- Sales trends
- Regional performance
- Customer insights
- Profitability analysis

---

## 📊 Key Insights
- West region generated highest sales
- Technology category was most profitable
- High discounts negatively affected profits
- Some products consistently generated losses

---

## 🚀 Project Outcome
Developed an end-to-end analytics solution using SQL, Python, and Power BI to support data-driven business decisions.
